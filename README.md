
# Customer Engagement & Retention Analytics

## Project Overview
This project analyzes banking customer engagement, product utilization, churn, and retention using Microsoft Power BI.

## Objectives
- Analyze customer churn and retention rates.
- Understand customer activity patterns.
- Examine banking product utilization.
- Identify customer groups that may require additional engagement.
- Provide data-driven retention recommendations.

## Tools and Technologies
- Microsoft Power BI
- Power Query
- DAX
- Data Visualization

## Dashboard Pages
1. Customer Retention Overview
2. Product Utilization Analysis
3. Customer Engagement & At-Risk Analysis
4. Retention Strength & Recommendations

## Project Files
- Power BI dashboard
- Research paper 

## Conclusion
The dashboard provides an interactive view of customer behavior and retention patterns to support business analysis and decision-making.
